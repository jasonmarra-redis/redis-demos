Why This Moment Matters
WatchFree+ is Vizio's #1 monetization surface. Every mid-roll break is a revenue event — but only if the right ad reaches the right household.
Generic contextual targeting yields $8–10 CPM. Marcus's Walmart-linked profile, combined with his ACR-validated auto affinity, commands $18–25 CPM from auto advertisers.

Stage 5: Segment Lookup & Frequency Check
Redis executes all pre-bid enrichment in <5ms
Six atomic Redis operations happen before a single OpenRTB bid request is built. Audience segment membership, frequency cap counters, deal eligibility, and Walmart propensity scores — all sub-millisecond lookups that would take 50–200ms against Databricks or a relational database.
Redis RAM Featureform
AUDIENCE_SEGMENTS:{device_id}
Pre-computed Databricks segment membership synced to Redis Set. Refreshed on 4h cycle. Multiple segments returned in single O(1) SMEMBERS call.
[auto_intender, walmart_auto, thriller_viewer, ...]0.4 ms
FREQ:{device_id}:FORD:F150:7D
Weekly frequency cap counter for Ford F-150 creative. Atomic INCR with TTL. Checked before inclusion in bid request.
1 of 3 (eligible)0.2 ms
FREQ:{device_id}:FORD:BRAND:7D
Brand-level cap across all Ford creative. Prevents over-exposure across campaigns running simultaneously via different DSPs.
2 of 5 (eligible)0.2 ms
VIEWING_CTX:{device_id}:NOW
ACR-detected current content written to Redis from Kinesis consumer. Provides content genre, channel, and daypart for OpenRTB content object enrichment.
thriller · prime · WatchFree+0.3 ms
DEAL:{ford_pmp_id}:FLOOR
Ford / The Trade Desk private marketplace deal floor price. Cached from ad server. Applied before OpenRTB auction fires to ensure deal eligibility.
$15.00 CPM floor · active0.2 ms
WALMART_PROPENSITY:{device_id}:AUTO
Purchase propensity score from Walmart Connect, pre-computed by Databricks, written to Redis. Appended to bid request as custom extension field.

Stage 9: The Architecture, Proven
Eight stages. Under ten milliseconds. One premium ad impression.
Kinesis, S3/Delta Lake, Databricks, and Walmart Connect feed Redis. Redis pre-enriches every impression in <2ms. The OpenRTB auction fires with signal-rich context. Magnite/SpringServe routes to the winning DSP. The result: a $18.40 CPM impression with closed-loop Walmart attribution — vs. $9.40 contextual without Redis.
