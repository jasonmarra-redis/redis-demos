Stage 2: Search Query
Jordan Chen searches "4K TV under $800"
A high-intent search query fires on BestBuy.com. Redis identifies a returning customer mid-purchase cycle and activates the unified search pipeline in under 5 milliseconds.
Search Session Event
JC
Jordan Chen
Best Buy member since 2021 | 3 prior TV research sessions | Last purchase: Sony soundbar, $349
HIGH INTENT
Query"4K TV under $800"
Query typeNavigational + filter intent
Session channelBestBuy.com / Chrome / Desktop
Prior search sessions3 TV research sessions last 14 days
Last session signalDwelled 2m 14s on Sony X90L PDP
Cart stateEmpty (comparison mode)
Inventory constraintSony X90L 65" back-ordered, 14 days
Why This Matters
Jordan has spent 3 sessions researching TVs. Purchase intent is high. The Sony he favors is back-ordered 14 days.
A generic SERP returns Sony X90L at position 1. Jordan sees "back order" and bounces. Best Buy loses a $700+ transaction to a competitor who has stock.
The opportunity: Redis knows Jordan's affinity, knows the Sony is out of stock, and can surface an in-stock alternative with identical specs and a strong cross-sell bundle - in the same query latency window Solr requires for lexical alone.
Without Redis: Static Solr SERP. No session context. No inventory signal. No affinity boost. Jordan sees the back-ordered Sony first, loses confidence, and checks Amazon.
Stage 3: Ingest
Best Buy's source systems flow into Redis
RDI handles real-time CDC from the product catalog, inventory, and customer graph. Featureform orchestrates the ML feature pipeline from Databricks and Kafka. The full 1.25M SKU index updates on write without a rebuild.

Agentic Commerce: The Next Horizon
CEO Corie Barry committed publicly that Best Buy is evolving BestBuy.com to be agentic-friendly, partnering with Google (UCP/Gemini) and OpenAI/ChatGPT. When an AI agent browses on a customer's behalf, it sends a natural language query - not a keyword. Redis LangCache sits in front of the vector index and grounds every agentic query in real-time inventory, pricing, and customer context before the LLM responds. The same Redis tier that solves the Unified Search problem is the foundation for every agentic commerce interaction Best Buy has publicly committed to building.
